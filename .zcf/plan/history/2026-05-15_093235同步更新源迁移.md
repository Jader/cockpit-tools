# 同步更新源迁移

## 背景
当前应用的更新、公告、发布脚本和文档仍指向 `jlcodes99/cockpit-tools`。用户要求全部切换到当前 `origin`：`Jader/cockpit-tools`。同时保留 `jlcodes99` 远程，方便后续手工同步上游功能。

## 目标
- 所有对外 GitHub 仓库链接切换到 `Jader/cockpit-tools`
- 更新检查与公告源切换到新仓库
- 发布脚本默认仓库切换到新仓库
- 文档、README、设置页等可见链接同步更新
- 保留 `jlcodes99` remote，不修改为应用运行时依赖

## 执行步骤
1. 批量定位并修改所有硬编码 `jlcodes99/cockpit-tools`、`github.com/jlcodes99`、`raw.githubusercontent.com/jlcodes99` 链接。
2. 更新 Tauri updater 配置中的 `latest.json` 来源到 `Jader/cockpit-tools`。
3. 更新公告加载源到 `Jader/cockpit-tools` 的 raw URL。
4. 更新发布脚本默认仓库和帮助文案。
5. 更新 README、README.en、DONATE、build 指南、SettingsPage、announcements、cask 文件等文档/界面链接。
6. 运行针对性搜索确认不再残留旧仓库链接（保留历史说明、git remote、FETCH_HEAD 等非代码产物除外）。
7. 运行必要检查，至少包含 `cargo check` 和前端类型检查/构建检查。

## 验收标准
- 应用运行时不再依赖 `jlcodes99` 仓库作为更新/公告/发布来源
- README 与文档中的外部链接均切到 `Jader/cockpit-tools`
- 发布脚本默认 repo 为 `Jader/cockpit-tools`
- `jlcodes99` 仍作为 git remote 保留，便于后续同步上游
